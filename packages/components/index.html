Public tokens inherited by nested components

Each left-hand example customizes only the outer component. Compare the nested component with its standalone control on the right. No example directly customizes the nested component's tokens.

1. Dialog → internal panel → user panel

The dialog forwards its warning header background and extra content space to its internal panel. The user panel also inherits those panel tokens. Its header and content spacing should match the standalone panel.
