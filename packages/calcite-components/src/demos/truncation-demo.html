calcite-list-item-group heading uses textTruncation property

textTruncation = { heading: "truncate" }

Code

          <calcite-list-item-group textTruncation={ heading: "truncate" } heading="longlonglonglonglonglonglonglong">...</calcite-list-item-group>

Pros

  • Do not require calcite-typography component
  • No potential BREAKING CHANGES

Cons/ Open questions

  • Configuring objects is not developer friendly
  • Requires lot of values to cover multiple truncation strategies with word-wrap, word-break & white-space
