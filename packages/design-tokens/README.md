# Calcite Design Tokens

## Getting Started

Install the design tokens module:

```bash
npm install @esri/calcite-design-tokens
```

Reference tokens in your CSS:

```css
@import "@esri/calcite-design-tokens/dist/css/index.css";

:root {
  --my-custom-token: var(--calcite-color-brand);
}
```

## Importing tokens

These are the key published asset files generated by the token transformer:

| Name           | Contents                                                                                              | CSS                                                  | SCSS                                                   |
| -------------- | ----------------------------------------------------------------------------------------------------- | ---------------------------------------------------- | ------------------------------------------------------ |
| semantic       | base semantic tokens (border, <br>corner-radius, font, opacity, <br>shadow, size, space, and z-index) | @esri/calcite-design-tokens/dist/css/semantic.css    | @esri/calcite-design-tokens/dist/scss/semantic.scss    |
| light          | semantic color tokens (light-mode)                                                                    | @esri/calcite-design-tokens/dist/css/light.css       | @esri/calcite-design-tokens/dist/scss/light.scss       |
| dark           | semantic color tokens (dark-mode)                                                                     | @esri/calcite-design-tokens/dist/css/dark.css        | @esri/calcite-design-tokens/dist/scss/dark.scss        |
| classes/mixins | semantic typography classes                                                                           | @esri/calcite-design-tokens/dist/css/classes.css     | @esri/calcite-design-tokens/dist/scss/mixins.scss      |
| index          | base semantic tokens + color <br>and typography                                                       | @esri/calcite-design-tokens/dist/css/index.css       | @esri/calcite-design-tokens/dist/scss/index.scss       |
| breakpoints    | semantic breakpoint tokens                                                                            | @esri/calcite-design-tokens/dist/css/breakpoints.css | @esri/calcite-design-tokens/dist/scss/breakpoints.scss |
